Taxi Agent & Dubins Car: Reinforcement Learning from Scratch in NumPy

An agent that is never given a model of its world has to learn only from states, actions and rewards, and a Q-table stops working once those states are continuous. I built two agents in pure NumPy to cover both cases: tabular Q-learning solves Taxi-v3 in 1000 of 1000 test episodes, and a Linear DQN that generalizes from hand-designed features steers a noisy car to the goal in 4 of 5 unseen environments.

Project Overview

Headline results

Taxi-v3: the learned Q-table delivers every passenger — 1000 of 1000 test episodes, no failures and no timeouts — averaging a return of 7.87 over 13.1 steps. Taxi's best possible average sits just under 8, so the policy is close to optimal.

Dubins car: the best checkpoint from a 21-run sweep reaches the goal in 4 of 5 unseen test environments with no truncated episodes, scoring +17.76, +17.75, +17.45 and +17.31.

What I Built

I wrote two reinforcement learning agents from scratch for UIUC CS440, using only NumPy with no PyTorch or RL library. The first is epsilon-greedy tabular Q-learning over Taxi-v3’s 500 × 6 Q-table, with pessimistic initialization and terminal-aware bootstrapping in the update rule. The second drives a car in a custom Gymnasium-registered Dubins-car environment with unicycle dynamics, noise added to its controls, polygon collision checks at every substep, shaped progress rewards and JSON-defined workspaces. That car sees obstacles only through a 16-beam lidar and has 30 steps per episode, so I used a Linear DQN, Q(s, a) = φ(s) · wa, over a 24-dimensional feature vector. The features cover goal geometry, heading error as sine and cosine, minimum lidar range and the 16 beam distances.

Design Decisions

I switched from a lookup table to linear function approximation over hand-built features for the car, because its continuous states are never revisited exactly; the features let one set of weights generalize across positions. I trained it with minibatches from a 50k-transition replay buffer and targets from a copy of the weights frozen for 100 updates at a time, which keeps linear Q-learning stable instead of diverging. I also had every run in the 21-run sweep write its own directory of weights, path plots and a results JSON, so the winning checkpoint traces straight back to the configuration that produced it.

The Result

On Taxi-v3, average return climbs from roughly −490 to near-optimal within about 1,500 episodes, and the final policy delivers every passenger in 1000 of 1000 test episodes. The best Dubins-car checkpoint reaches the goal in 4 of 5 unseen test environments with no truncated episodes.

Key Features

Tabular Q-learning on Taxi-v3 with epsilon-greedy exploration; a 24-dimensional feature design built from goal geometry and lidar returns; a replay buffer and frozen target weights for stable linear Q-learning; a custom Dubins-car environment with action noise, collision checking and shaped rewards; and a reproducible 21-run sweep where every run keeps its weights, plots and results.
