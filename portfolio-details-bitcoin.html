Bitcoin Price Prediction: Forecasting Price from On-Chain Activity

Bitcoin’s price drifts and swings, and its on-chain predictors are all correlated with one another, so it is hard to tell how much of the daily price that activity can actually explain. I compared Linear, Ridge, and Lasso regression on the same lagged features and the same chronological split; plain linear regression won, cutting RMSE 82% below a mean baseline.

Project Overview

What the numbers said

Best model: plain linear regression on a 7-day lag window — RMSE 978.4, against a mean-predictor baseline of roughly 5570, an error reduction of about 82%.

The surprise: Ridge came in at 1150.7 and Lasso at 2191.4. Shrinkage bought stability this dataset never needed, and Lasso’s L1 penalty dropped predictors that were carrying real signal.

What I Built

This is a time-series regression study built in Python with scikit-learn, pandas, NumPy, and mlxtend, as the sole author for UIUC CS 598, Practical Statistical Learning. The dataset holds 2,920 daily observations of Bitcoin network activity across 23 variables. I kept four of them, trade volume, transaction count, estimated USD transaction volume, and output volume, and expanded each into lagged copies: 12 predictors at a 3-day window and 28 at 7 days. I forward-filled the missing values that building lags creates and dropped the leading rows that don’t line up. Then I fit OLS with sequential forward selection, RidgeCV, LassoCV, and a constant-mean baseline, and scored each one by RMSE on the same held-out period.

Design Decisions

I split the data by date, 80/20, because a price series cannot be shuffled; the test set is always later than the training set, so no model ever trains on the future and every score reflects real forecasting. I held the features and the split fixed and changed only the model, which means the RMSE differences come from the models themselves. I also chose four variables I could explain, each standing for liquidity, demand, economic activity, or coin movement, which keeps the model readable, and I ran the 3-day and 7-day windows separately so the effect of more history could be measured directly.

The Result

Plain linear regression on the 7-day window scored the best RMSE of 978.4, against roughly 5570 for the mean baseline, an error reduction of about 82%. Ridge reached 1150.7 and Lasso 2191.4, so regularization did not help on this data. Moving from a 3-day to a 7-day window lowered linear RMSE from 1384.6 to 978.4.

Key Features

An interpretable four-variable on-chain feature set; 3-day and 7-day lag windows treated as a controlled variable; a leakage-free chronological split with forward-fill and leading-row removal (2,333 train / 584 test rows at L=3, 2,330 / 583 at L=7); two kinds of feature selection, sequential forward selection for OLS and the L1 penalty for Lasso; and a four-way RMSE comparison of Linear, Ridge, Lasso, and a mean baseline on the same held-out period.
