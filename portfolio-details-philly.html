Philly Restaurant Recommender: Ranking Restaurants on Review Text Alone

A team course project that ranks Philadelphia’s 200 most-reviewed restaurants by what ~90,000 Yelp reviews say, instead of by cuisine tags or price.

Project
Review-Based Retrieval & Ranking System
Context
CS410 Text Information Systems — team course project
Data
Yelp Open Dataset — ~90,000 reviews across the top 200 Philadelphia restaurants
Stack
Python 3.8, gensim, rank-bm25, NLTK, transformers, pandas

Project Overview

The pipeline, in numbers

200 restaurants, ~90,000 reviews, 3 retrieval algorithms and 4 sentiment analyzers — each of the four scores every review, then all four are put on a common scale before either half of the ranking counts.

Sentiment is combined per restaurant two ways: a plain average, and a weighted average that leans on reviewers with more history and more useful votes.

What We Built

Built as a team for CS410 Text Information Systems. We pooled each restaurant’s Yelp reviews into one document and scored free-text queries against it with three retrieval methods: BM25, Word2Vec and pivoted length normalization. Four sentiment analyzers (VADER, TextBlob, SentiWordNet and BERT) scored every review, and their scores were converted to z-scores and averaged so no single analyzer’s scale dominated. Relevance and sentiment combine into one weighted score that ranks the restaurants.

The Result

Type a craving like “Japanese sushi” and get a ranked top 10, 25 or 50 list. Example rankings for each retrieval method are saved in the repo.
