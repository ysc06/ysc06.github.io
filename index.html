Adaptive Insights — Persistent User Preferences

Agentic AI — personalization & agent memory

2026 IBM watsonx Hackathon — participating project

My contribution to our hackathon entry, an analytics UI where a local Llama 3.2 model decides how each answer is drawn: the layer that makes it remember you. An LLM intent classifier tells a preference from a question — “use bar charts by default” gets stored, “show revenue by region” gets answered — and theme, palette, chart type and number format persist per user across sessions. A three-tier precedence rule settles the conflict when a stored default, a phrase in the live prompt, and the model’s own plan each want a different chart.
