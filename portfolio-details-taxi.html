Reinforcement Learning Project

Taxi Agent & Dubins Car

Two agents that learn to act in environments they are never given a model of — they only see states, choose actions, and receive rewards. The first solves a small discrete world with a Q-table. The second throws the table away: its state space is continuous, so it has to generalize from hand-designed features, steering a car with noisy controls around obstacles it perceives only through a 16-beam lidar.

Project Overview

Headline results

Taxi-v3: the learned Q-table delivers every passenger — 1000/1000 evaluation episodes, no failures and no timeouts — averaging a return of 7.87 over 13.1 steps. Taxi's optimal average sits just under 8, so the policy is essentially optimal.

Dubins car: the best checkpoint of a 21-run sweep reaches the goal in 4 of 5 held-out test environments with zero truncated episodes, scoring +17.76, +17.75, +17.45 and +17.31.

Both agents were written from first principles for UIUC CS440 — no PyTorch and no RL library, just NumPy. The point was to build the update rules myself and then live with the consequences: tuning exploration, designing features, and reading training curves to work out why a run failed.

The Challenge

A Q-table works beautifully for Taxi's 500 discrete states, and not at all for a car whose pose is continuous. The second agent had to learn from a state it can never revisit exactly, using controls perturbed by noise before the environment ever applies them, and an obstacle map it only glimpses through 16 lidar returns — all within a 30-step episode budget.

My Approach

For Taxi, epsilon-greedy tabular Q-learning with pessimistic initialization. For the Dubins car, linear function approximation — Q(s, a) = φ(s) · wa over a 24-dimensional feature vector — stabilized with an experience replay buffer and periodically frozen target weights, then narrowed down through a 21-run hyperparameter and feature-design sweep with every run preserved for comparison.

Key Features

From a 500-state lookup table to feature-based generalization under noise — two agents, one learning problem, two very different answers.

Tabular Q-Learning on Taxi-v3

Epsilon-greedy action selection over a 500 × 6 Q-table, with terminal-aware bootstrapping in the update rule. Average return climbs from roughly −490 to near-optimal within about 1,500 episodes.

24-Dimensional Feature Design

Goal geometry, heading error as sine and cosine, minimum lidar range, and 16 raycast beam distances — the hand-built representation that lets a linear model generalize across a continuous pose space.

Replay Buffer & Target Weights

Minibatches sampled from a 50k-transition buffer, with bootstrap targets drawn from a weight copy frozen for 100 updates at a time — the two ingredients that keep linear Q-learning from diverging.

Custom Dubins-Car Environment

A Gymnasium-registered unicycle-dynamics environment with action noise, per-substep polygon collision checking, shaped progress rewards, and JSON-defined workspaces for training and held-out evaluation.

Reproducible 21-Run Sweep

Every training run writes its own directory of weights, per-environment path plots, and a results JSON, so the winning checkpoint can be traced back to the configuration that produced it.
